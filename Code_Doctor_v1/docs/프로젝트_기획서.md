# Code Doctor 수행평가 기획서 초안

1. **프로젝트명:** Code Doctor — API 기반 프로그래밍 오류 분석 및 해결 기록 시스템
2. **문제 상황:** 코딩 중 같은 오류를 여러 차례 경험해도 예전에 어떤 해결 방법을 사용했는지 찾기 어렵다. 외국어로 작성된 해결 자료를 이해하는 데 시간이 걸린다.
3. **대상 사용자:** Python/Streamlit을 공부하는 학생 및 초급 개발자
4. **핵심 기능:** 오류 입력, 오류 유형 자동 분류, Python 문법 검사, Stack Exchange 질문·답변 검색, DeepL 번역, PyPI 정보 조회, 오류 기록 SQLite 저장·검색·수정·삭제, 상태별 통계
5. **데이터 구조:** `error_records`의 id/title/language/environment/error_type/error_message/source_code/description/expected/actual/cause/solution/status/created_at/updated_at; `bookmarks`의 id/error_id/question_id/answer_id/question_title/question_url; `translation_cache`의 fingerprint/target_language/translated.
6. **화면 구성:** 사이드바 4개 메뉴(오류 분석·검색, 저장 기록, 오류 통계, API·사용 안내). 검색 화면에서 로컬 문법 검사 → 질문 API 검색 → 선택한 질문 답변 API 요청 → 자동 번역. 저장 기록 화면에서 CRUD 수행.
7. **테스트 계획:** 정상 입력/빈 검색어/없는 질문/문법 오류/문법 통과/DB 재실행 유지/중복 북마크/API 연결 실패/키 미설정 등 테스트. 수동 측정 결과와 수정 내용은 별도 기록.

**구현 범위:** 코드를 실행하지 않으며 런타임 오류와 논리 오류의 자동 수정은 지원하지 않는다. 외부 API 오류와 번역 실패 시 프로그램에서 사용자에게 오류를 안내하고 원문을 보여준다.

**진로 연계:** 개발 현장의 이슈 추적과 오류 분석 과정을 사용자 중심 웹 프로그램으로 구현하면서 DB, API, 테스트, 예외 처리의 역할을 익힌다.

> 이 문서는 검토·수정용 초안입니다. 실제 구현·테스트 후 발견 사항을 본인 결과에 맞게 적으세요.
